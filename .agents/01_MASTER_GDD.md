# 마스터 게임 기획서 (GDD): 2D 경찰 수사 OS 분석 & LLM 현장 지휘·심문 추리 게임

> **프로젝트 코드명**: `ColdCaseOS` (가제)  
> **개발 엔진**: Unity (C#, 2D URP 기준)  
> **최종 업데이트**: 2026-11-28 (LLM 현장 지휘 & 사건 관련자 전원 심문 통합 개편판)

---

## 1. 프로젝트 개요 및 핵심 정체성

* **장르**: 2D 경찰 수사 OS(`K-POL OS`) 기반 문서·포렌식 분석 + **LLM 현장수사반 지휘 & 사건 관련자 전원 심문** 추리 게임
* **시대 및 배경**: 현대 대한민국 (2020년대). 다크 모드 경찰청 전용 인트라넷 수사 OS(`K-POL OS`) 위에서 일선 경찰서의 초동 수사 기록을 이관받아 재검토하고, 스캔 서류·로그·블루프린트·현장 사진·CCTV를 다중 창으로 교차 분석하며 **휘하 현장수사반 지시**와 **사건 관련자 전원 심문**을 지휘.
* **핵심 재미 (Core Pillars)**:
  1. **능동적 현장수사반 지휘 (LLM Tool Calling)**: 정해진 버튼 나열이나 2D 지도 미니게임 대신, **전담수사팀장**으로서 현장수사반(현장반장 강민호 경사)에게 자연어로 수색·재감식·알리바이 로그 조회·영장 집행·가설 검증을 지시하고 결과물을 OS로 수신.
  2. **사건 관련자 전원 심문 & 증거 제시 심리전 (LLM + Prompt Isolation)**: 용의자·목격자·최초 발견자를 구분하지 않고 사건 관련자 전원을 동일 조건으로 심문. 전원에게 분 단위 사건 시간 알리바이와 숨기는 사정을 부여하며, **증거판 카드를 직접 첨부해 추궁**함으로써 거짓말 방어막과 평정심을 무너뜨림.
  3. **결정론적 교차 검증 & 증거판 중심 최종 추리**: 사건의 진실·분 단위 타임라인·증거 해금·비밀 폭로 조건은 Unity C# 상태 머신과 JSON 데이터가 100% 통제(환각·탈옥 원천 차단). 문서 드래그·포렌식 확대 캡처·심문 발췌로 증거판에 올린 카드만 최종 송치 보고서(`[범인]`, `[범행 동기]`, `[사용 흉기]`, `[침입·은폐 수법]`) 선택지에 노출.

## 2. 세계관, 인물 및 전체 에피소드 구성

### 주요 인물
* **주인공 — 한도현 경감 (34세, 서울청 중요사건 보완·재수사 전담팀장)**: 과거 강력계 현장 부상 이후 내근 분석·지휘 보직으로 전향. 일선 경찰서 초동 수사 중 오류나 이상 징후가 포착된 사건을 이관받아 `K-POL OS`에서 기록을 전면 재검토하고, 휘하 현장수사반 지휘 및 사건 관련자 직접 심문을 총괄.
* **현장수사반 반장 — 강민호 경사 (39세, 휘하 현장수사반 대표 보고 창구)**: 베테랑 현장 형사. 팀장의 자연어 지시를 받아 감식·탐문·외부 로그 조회·영장 집행을 수행해 결과 파일(서류·사진·CCTV·로그)을 `K-POL OS`로 전송. 근거 없는 영장 요청이나 무관한 노이즈 지시를 사전 필터링하고, 확보된 단서 범위 내 가설 검증 의견 제시 역할을 겸임.
* **최종 흑막 — 서진우 (45세, 코드네임 '설계자')**: 전직 경찰청 디지털포렌식센터 수석이자 `K-POL OS` 원개발자. 5년 전 증거 조작 누명으로 파면된 뒤 지하 증거 세탁 네트워크 구축.
* **경찰 내부 내통자 — 박정태 총경 (52세)**: 현직 서울청 수사국 간부. 순찰 일정 및 신변보호 해제 정보 등을 서진우 측에 유출.

## 3. 핵심 게임 루프 및 시스템 규칙

### 3.1. 기본 게임 루프 (5단계)
1. **사건 이관 (브리핑)**: 일선 초동팀이 작성한 최소 초기 자료(초동 보고서, 의료 소견서, 1차 간략 조서, 도면, 초기 사진·CCTV)가 `K-POL OS`에 이관됨. 승계된 법정 영장/송치 시한 및 휘발성 골든 타임 표시.
2. **OS 정밀 분석 (시간 정지 — 0분)**: 서류 열람, 사진/CCTV 확대·보정 캡처, `K-POL DB` 신원 조회, 증거판 정리, 현장반장과의 가설 검증 대화 진행. **분석·추리·질문 고민 중에는 시간이 흐르지 않음.**
3. **현장수사반 지시 (LLM Tool Calling & 시간 소모)**: `[현장수사반]` 앱에서 자연어로 수색·재감식·외부 로그 조회·영장 집행을 지시(필요 시 증거판 카드 첨부). LLM이 허용된 결정론적 액션으로 매핑하면 `[지시 확정: 예상 소요 OO분]` 확인 후 즉시 시간이 경과하고 신규 문서·사진·로그가 도착.
4. **사건 관련자 전원 심문 (LLM 상태 머신 & 시간 소모)**: `[용의자 심문]` 앱에서 관련자 중 1명을 소환(**전원 동일 세션 비용: 45분 / 최대 8턴**). 자유 질문과 **증거판 카드 첨부 제시**로 거짓말 레이어와 평정심을 무너뜨리고, 핵심 진술을 증거판 카드로 발췌하거나 추가 녹취록을 해금.
5. **최종 송치 보고서 제출 및 정산**: 증거판에 모은 카드로 `[범인]`, `[범행 동기]`, `[사용 흉기]`, `[침입·은폐 수법]` 4슬롯을 완성해 제출. 소요 시간 구간에 따라 3단계 동적 체포 보고서와 신뢰도 정산 출력.

### 3.2. 행동 기반 시간 계산 및 법정 시한 명분
* **법적·서사적 시한 명분**: 대한민국 형사소송법 제200조의4(긴급체포 후 **48시간 이내** 구속영장 청구) 및 제202조(경찰 구속 수사 기간 **10일**)에 근거해, 일선 초동팀이 긴급체포 또는 종결 직전 이관한 사건의 잔여 법정 시한(EP 1 기준 `16시간 / 960분`)을 전담팀이 승계함.
* **결정론적 시간 소비 규칙**:
  * 별도 2D 지도 이동 계산 대신, 각 현장수사반 액션에 확정 소요 시간(`30분 ~ 90분`)을 부여하고 전담팀 신뢰도(`Lv 0 ~ Lv 5`)에 따른 기관·감식 작업 시간 보정을 적용.
  * 심문 세션 소환 시 **모든 관련자 동일 `45분` 차감** (UI 비용 차이로 용의자/목격자를 추측하는 메타 스포일러 차단 + 유저당 LLM API 호출 상한 통제).
  * 무관한 노이즈(지구대 민원 등)나 근거 부족 영장 지시는 현장반장이 **`0분` 사전 필터링**으로 안내해 억울한 시간 낭비 방지.

### 3.3. 하이브리드 LLM 통제 원칙 (환각·탈옥 0% 보장)
* **진실 단일 공급원(SSOT)**: 타임라인, 증거 ID, 해금 조건, 비밀 레이어 개방 조건은 모두 Unity C# 코드와 `epXX.json`에만 존재.
* **프롬프트 격리(Prompt Isolation)**: 용의자 심문 시 C# 상태 머신이 해금하지 않은 상위 비밀 레이어의 정보는 LLM API 요청 본문에 아예 포함하지 않음.
* **불변 알리바이 주입**: 심문 가능한 모든 사건 관련자에게 사건 시간대 분 단위 알리바이(`immutableTimeline`)를 부여해 시스템 프롬프트에 고정 삽입함으로써 시각 환각 차단.
* **구조화 출력(Structured Output)**: 현장수사반과 심문관 모두 정해진 JSON 스키마로 응답해 표정(`emotion`), 평정심 변동(`composureDelta`, 코드 클램핑), 액션 ID(`matchedActionIds`), 발췌문(`extractableStatement`)을 결정론적으로 연동.

### 3.4. 최종 보고서 검증 및 시간 초과 규칙
* **수정 허용형 추리 검증**: 오답 제출 시 해당 슬롯의 논리적 허점을 짚어주는 맞춤형 피드백을 반환하며 수정 기회 부여(영구 게임오버 없음).
* **제한 시간 초과 시 처리**: 송치 마감 초과 시 강제 종료 대신 **연장 수사 모드(`IsOvertime`)**로 자동 전환되어 끝까지 추리를 완주할 수 있으며, 최종 정산 시 체포 보고서 3티어 분기와 전담팀 신뢰도(`-1`)에만 반영. (재도전/체크포인트 되감기 별도 지원)

## 4. 2D 화면 레이아웃 및 UI/UX 명세 (1920×1080 경찰 수사 OS 기준)

화면 전체를 **다크 모드 경찰청 전용 수사 OS(`K-POL OS`) 바탕화면**으로 구성합니다. 모든 도구가 독립된 `OSWindow` 창으로 작동하므로 서류, CCTV, 현장수사반, 심문 창을 나란히 띄워 동시에 비교·작업할 수 있습니다.

### 상단/하단 고정 OS 작업표시줄 (HUD)
* `[좌측]` 현재 사건 번호·핵심 목표 요약 / 현재 인게임 시각(`YYYY.MM.DD HH:mm`)
* `[중앙]` **남은 송치 시한 (`16:00`) & 휘발성 골든 타임 (`12:00`)**
* `[우측]` 핵심 앱 6종 빠른 실행/전환 아이콘: `[파일 탐색기]` / `[디지털 증거판]` / `[경찰 DB]` / `[현장수사반]` / `[용의자 심문]` / `[최종 보고서]`

### OS 핵심 앱 윈도우 6종 + 뷰어 2종
1. **사건 파일 탐색기 (`FileExplorer`)**: 해금된 문서·사진·CCTV·심문 녹취 목록을 카테고리별 필터 및 `NEW` 뱃지로 관리.
2. **문서 & 사진/CCTV 포렌식 뷰어 (`DocumentViewer`, `PhotoInspector`, `CctvVideoController`)**:
   * **문서 뷰어**: 본문 스포일러 표시 없이 자유 텍스트 드래그 시 **3버튼 플로팅 툴바(`[+ 증거판 등록]` / `[K-POL DB 조회]` / `[현장반에 확인 지시]`)** 팝업.
   * **사진/CCTV 분석기**: `Unity VideoPlayer` 타임라인 스크러빙·단축키(`Space`, `←/→`), `2.0x~4.0x` 돋보기 확대, 명암/대비 보정, 정밀 영역 캡처(전체 통캡처 금지).
3. **경찰 통합 조회 DB (`PoliceDB`)**: 이름·차량번호·법인명 정규화 검색. 법적 절차상 기본 신원·전과·주소지만 출력하며, 금융·통신 등 영장 대상 정보는 현장수사반 영장 액션으로 분리.
4. **현장수사반 지휘 채널 (`FieldCommand`)**: 강민호 경사 대표 보고 창구. 자연어 지시 + 증거판 카드 첨부 + 동적 추천 칩(백지 공포 방지) + `[지시 확정: 예상 소요 OO분]` 확인 카드 + 0분 가설 검증.
5. **조사실 심문 창 (`Interrogation`)**: 사건 관련자 전원 목록(동일 `45분/8턴` 소환, 의식불명 등 예외 사유 명시), 표정 연동 초상화, 평정심 게이지(`0~100`), 붕괴된 거짓말 배지, 증거판 카드 첨부(최대 2장), 심문 진술 원클릭 증거판 등록.
6. **디지털 증거판 (`EvidenceBoard`) & 최종 보고서 (`Report`)**:
   * **증거판**: 텍스트 발췌·사진/CCTV 캡처·DB 조회·심문 진술 카드를 자유 배치, 핀-실 연결, 카드 하단 메모·포스트잇, `[기각]` 및 `[폐기함 복구]`. 모은 카드는 **현장반 영장 근거** 및 **심문 증거 제시 무기**로 직접 소비.
   * **최종 보고서**: 증거판에 등록된 활성 카드 중에서 `[1. 범인]`, `[2. 범행 동기]`, `[3. 사용 흉기]`, `[4. 침입·은폐 수법]` 4슬롯을 선택·제출.

## 5. 나노바나나(2D 이미지 생성) 아트 파이프라인 가이드

소규모 개발에서 일관된 고품질 2D 비주얼을 유지하기 위한 제작 원칙입니다. (세부 목록 및 프롬프트는 [11_EP01_ART_ASSET_SPEC.md](./11_EP01_ART_ASSET_SPEC.md) 참조)

1. **텍스트와 이미지의 완전 분리 (필수)**: 서류·영수증·로그 내부 글자와 타임스탬프는 AI로 생성하지 않고 Unity **TextMeshPro(TMP)**로 렌더링.
2. **CCTV 영상 클립 제작법**: 고정 기준 배경(`BASE`) 1장 생성 후 Start/End 프레임 편집 → `First + Last Frame` 기반 5초 클립 추출(물리 접촉 배제).
3. **확정 아트 컨셉 및 상표권 가이드**:
   * **확정 화풍**: **인디 리소그래프(Risograph) & 거친 스크린프린트 일러스트** — 굵은 손그림 잉크 외곽선, 거친 종이 섬유 질감, 무광 건조 잉크 마감 + 현실 공간의 저채도 멀티컬러(`Muted Natural Color`).
   * **실존 상표명·기업명 사용 금지**: 모든 기업·호프집·보안업체·물류사·앱 명칭은 가상 명칭 사용(예: `세이프가드`, `별밤호프`, `한빛물류`, `포커스 스터디카페`).
