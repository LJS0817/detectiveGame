# EP01 LLM 기반 현장 지시 & 전원 심문 상세 설계서 (Rev. 2)

> **문서 목적**: [01_MASTER_GDD.md](./01_MASTER_GDD.md), [02_EPISODE_01_SPEC.md](./02_EPISODE_01_SPEC.md), 그리고 `Assets/Data/Episodes/EP01/ep01.json`을 기반으로, **전담수사팀장(플레이어) ↔ 휘하 현장수사반(LLM Tool Calling) ↔ 사건 관련자 전원 7인(LLM 상태 기반 심문)** 구조의 완전 명세를 정의합니다.  
> **핵심 설계 원칙**:
> 1. **결정론적 진실 통제**: 사건의 진실·분 단위 타임라인·증거 해금·비밀 폭로 조건은 Unity C# 상태 머신과 JSON 데이터가 100% 통제하며, LLM은 자연어 해석(Parser)과 캐릭터 연기(Actor)만 담당합니다.
> 2. **관련자 전원 심문 & 메타 스포일러 차단**: 핵심 용의자와 목격자·최초 발견자를 구분하지 않고 **사건 관련자 7인 전원을 동일한 비용과 인터페이스로 심문 가능**하게 구성하며, 전원에게 **사건 시간대(`01:00~02:30`) 분 단위 알리바이와 세부 인격·숨기는 사정**을 부여합니다.
> 3. **프롬프트 격리(Prompt Isolation)**: 코드가 해금하지 않은 상위 비밀 레이어 정보는 LLM 요청 본문에 포함하지 않아 유도/탈옥에 의한 조기 자백을 원천 차단합니다.

| :--- | :--- | :--- |
| **플레이어** | **서울청 중요사건 보완수사 전담팀장 (경감)** | 일선서 초동 기록을 `K-POL OS`로 이관받아 재검토. 휘하 현장수사반에 수색·감식·알리바이 조회·영장 집행을 직접 하달하고, 사건 관련자 전원을 소환 심문한 뒤 최종 송치 보고서를 제출. |

### 1.2. 행동 기반 제한 시간 규칙 (대한민국 형사소송법 정합성)
* **시한 명분**: 일선 초동팀이 `2026.11.18 02:40` 김철수를 긴급체포함. 대한민국 형사소송법 제200조의4(긴급체포 후 48시간 이내 구속영장 청구) 기준, 검찰 검토 및 영장실질심사 준비 시간을 제외한 **전담팀 배정 보완수사 시한 = `16시간(960분)`** (`2026.11.18 09:00` → `2026.11.19 01:00`).
* **휘발성 골든타임**: `12시간(720분)` (`2026.11.18 21:00`). 이 시간 내에 NVR 포렌식(`ACT_FORENSIC_NVR`)을 완료해야 EP 2·7 복선인 원본 IP·연동 계좌 끝자리(`EV_META_EP01_FULL_IP`)가 온전히 확보됨.
* **시간 소모 원칙 (`TimeManager.cs` 연동)**:
  * **0분 (시간 정지)**: 문서·사진·CCTV 열람, `K-POL DB` 기본 조회, 증거판 정리, 현장반장과의 가설 검증 대화, 무관 노이즈 사전 필터링, 질문 고민 중.
  * **시간 소모**:
    * **현장수사반 액션 14종**: 액션별 **30분 ~ 75분** (총합 `645분` = 10시간 45분)
    * **사건 관련자 심문 세션 1회 소환**: 전원 동일 **45분 / 최대 8턴** (7인 각 1회 소환 시 총합 `315분` = 5시간 15분)
  * **전체 시간 예산 검증**: 현장 액션 14종 전부(`645분`) + 관련자 7인 전원 1회 심문(`315분`) = **정확히 `960분`(16시간 00분)**. 불필요한 중복 심문을 줄이고 단서를 좁히면 **8~11시간(480~660분)** 내 클리어 가능. 초과 시 연장 수사(`IsOvertime`, 등급 하락) 허용.

## 2. EP01 자료 단계화 및 기존 `ep01.json` 정비 명세

### 2.1. 기존 `ep01.json` 5가지 필수 정비 항목
1. **`EV_DOC_SECURITY_ALIBI` 합본 분리**: 세이프가드 로그 + 4인 알리바이 합본을 **5개 개별 문서**로 분리(`EV_DOC_SAFEGUARD_LOG`, `EV_DOC_ALIBI_KIM_PC`, `EV_DOC_ALIBI_CHOI_DRIVER`, `EV_DOC_ALIBI_HAN_DORM`, `EV_DOC_ALIBI_LEE_ONEROOM`).
2. **목격자·최초 발견자 알리바이 검증 로그 3종 신설**: 전원 심문 및 알리바이 교차 검증이 가능하도록 `EV_DOC_ALIBI_OH_HOF`(별밤호프 POS/발주/CCTV), `EV_DOC_ALIBI_JUNG_GPS`(한빛물류 GPS/PDA 스캔 로그), `EV_DOC_ALIBI_YOON_TAXI`(최초 신고자 윤서진 택시 결제/하차 CCTV/112 녹취) 추가.
3. **최초 발견자('첫 손님') 실명·프로필 부여**: 기존 `EV_DOC_INIT_REPORT`의 익명 `"첫 손님"`을 **`윤서진(29, 여 / 인근 오피스텔 거주 야근 IT 디자이너)`**으로 구체화해 초동 보고서와 `K-POL DB`에 등재.
4. **`PoliceDB` 이준호 금융 스포일러 분리 & `EV_DOC_STMT_HAN` 개편**: 기본 DB의 이준호 도박·`-9912` 송금 내역은 영장 문서(`EV_DOC_FINANCE_LEE`)로 이동. 한소라 초기 조서는 축소 진술본(`EV_DOC_STMT_HAN_INIT`)만 제공하고 핵심 증언은 심문 `Layer 2`(`EV_DOC_STMT_HAN_FULL`)로 이동.
5. **사진·CCTV 히트박스(`hitboxes`) 보강**: 현재 빈 배열(`[]`)인 사진 5장·CCTV 1개에 `evidenceId` 매핑 추가.

### 2.2. Phase 0: 초기 이관 자료 (`isInitial: true`) — 문서 8종 + 사진 3장 + CCTV 1개
* `EV_DOC_INIT_REPORT`: 초동 수사 보고서 — 사건 개요, 김철수 긴급체포, 흉기 후보 4종, 실버 팔찌, CCTV `01:55~02:05` 누락, 뒷문 잠금, **관련자 7인 성명 및 역할 등재(전원 심문 목록 즉시 등록)**
* `EV_DOC_MEDICAL`: 응급실 진단서 및 상처 미세물증 소견 (`'사장님'` 호칭, 직경 10~12cm 원통, 적색 에나멜, 제1인산암모늄, 박성훈 48시간 진술 불가)
* `EV_DOC_BLUEPRINT_TIMES`: 건물 구조 안내 및 구간별 실측 이동 시간표
* `EV_DOC_STMT_KIM`: 초동 피의자 1차 조서 — 김철수
* `EV_DOC_STMT_LEE`: 초동 참고인 1차 조서 — 이준호 (3중 거짓말)
* `EV_DOC_STMT_CHOI`: 초동 참고인 1차 조서 — 최태식 (`'박 사장'` 호칭)
* `EV_DOC_STMT_HAN_INIT`: 초동 참고인 1차 간략 조서 — 한소라 (`"22시 퇴근 후 바로 기숙사, 특이사항 없음"`)
* `EV_DOC_STMT_YOON_INIT`: 112 최초 신고자 간략 접수 기록 — 윤서진 (`02:30` 최초 발견 및 신고 시각만 기재)
* 초기 사진 3장: `EV_PHOTO_BLUEPRINT`, `EV_PHOTO_INIT_STORAGE`, `EV_PHOTO_INIT_COUNTER`
* 초기 CCTV 1개: `EV_CCTV_EP01_03` (`02:14` 매장 정면)

## 4. EP01 사건 관련자 전원(7인 심문 가능 + 2인 불가) 상세 프로필 & 알리바이 명세

> **LLM 타임라인 환각 방지 규칙**: 아래 각 인물의 `분 단위 사건 시간 알리바이(minuteTimeline)`는 해당 인물의 시스템 프롬프트에 **불변 사실 블록(Immutable Fact Table)**으로 고정 삽입됩니다. LLM은 이 표에 없는 시각·행적을 임의로 창작할 수 없으며, 기억이 나지 않거나 모르는 타인의 행적에 대해서는 모른다고 답해야 합니다.

### 4.1. 심문 불가 예외 2인 (명시적 사유 표시)
* **박성훈 (48, 남 / 피해자 점주)**: 심문 목록에 표시되나 **`[심문 불가: 관악병원 중환자실 입원 — 급성 뇌진탕으로 48시간 진술 불가]`** 잠금 상태 (`EV_DOC_MEDICAL`과 일치).
* **`W.A.` / `WIPE_ADMIN` (신원 미상)**: 성수동 구 공단 인근 발송인. EP01 시점 신원 미특정으로 소환 불가 (EP 2·7 직결 복선).

### 5.2. Structured Output JSON 스키마 (현장수사반 / 심문 공용 원칙)
* **현장수사반 응답**: `{ "replyDialogue", "matchedActionIds": [], "isHypothesisCheck": bool }`
* **심문관 응답**: `{ "dialogue", "emotion": "calm|annoyed|nervous|panicked|broken|cooperative", "composureDelta": int, "extractableStatement": string }`
  * 증거 미첨부 일반 턴에서는 Unity 코드가 `composureDelta`를 `[-10, 0]`으로 강제 클램핑.
  * `immutableTimeline`과 `unlockedLayers`만 시스템 프롬프트에 조합(잠긴 레이어는 요청 페이로드에서 완전 배제).

### 5.3. 전원 심문 도입에 따른 트레이드오프 및 대응책
* **제작 부하 증가 (EP 1~7 확장 시)**: 에피소드당 6~8명의 상세 알리바이·레이어 작성 필요 → 위 `InterrogationProfileData` JSON 템플릿 표준화로 코드 수정 0, 데이터 작성만으로 확장.
* **API 호출량 증가**: 7인 중 4~7인을 심문할 경우 에피소드 완주당 예상 호출 약 `35~55회` → 경량 고속 모델(예: Gemini Flash 계열) + 세션당 8턴/45분 제한으로 비용 상한 예측 가능.
* **타임라인 정합성 검증**: `immutableTimeline`을 모든 인물의 프롬프트에 필수 주입하고, 테스트 단계에서 JSON 검증 스크립트로 인물 간 교차 시각 모순 여부를 자동 검사.
